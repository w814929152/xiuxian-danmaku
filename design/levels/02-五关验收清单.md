# 五关 × 全阶段验收清单

> 设计：文策渊 · 任务 L5-DESIGN-02 · 2026-09-22
> **本文件是判定表，不是设计稿。** 设计口径的唯一权威是 `design/levels/01-五关设计总纲.md`（下称「总纲」），本文件只做三件事：把总纲拆成可观测的格子、给每格一个期望值、标明期望值的出处。
> **冲突处置**：本文件与总纲冲突 → 以总纲为准并回报；本文件与代码冲突 → **不自行改设计**，报 team-lead 裁决。

## 0. 怎么用这份清单

### 0.1 三列的含义

| 列 | 含义 |
|---|---|
| **观测项** | 实测时**用眼睛/手感能直接确认**的一件事。写"看到什么"，不写"代码怎么走" |
| **期望值** | 应该看到的结果。带数字的写死数字，带行为的写死行为 |
| **判据来源** | 这个期望值从哪来：`§X` = 总纲章节；`代码 Xxx.gd:字段` = 已落地的常量；`实测` = 只能靠跑一遍确认（无文字依据） |

### 0.2 判定符号

| 符号 | 含义 | 处置 |
|:--:|---|---|
| 🔴 | **不可回归项**。缺失/走样即支柱漂移，**不允许**为了过门禁或省事而删掉 | FAIL 即阻塞，必须修 |
| 🟠 | 高风险项。缺失会明显伤害体验，但不至于支柱漂移 | FAIL 需排期修 |
| 🟡 | 一般项。数值/表现偏差 | 记录，按容差判 |
| ✅ | 观测通过 | — |

### 0.3 容差口径（先说好，免得现场扯皮）

| 项 | 容差 |
|---|---|
| 时长（波次 / 单关） | **±5s**（独有怪首登横幅 +0.5~1.2s 本就计入） |
| 血量 / 只数 / 格数 | **零容差**（这是数据表，不是手感） |
| 护罩轮转 CD / 预告时长 / 窗口时长 | **±0.1s** |
| 分数 / 品阶阈值 | **零容差**（落账分必须逐位对得上总纲 §G.3 / §G.4） |
| 弹幕发数 / 扇形弧度 | 发数 **±1**，弧度 **±0.05rad** |

### 0.4 建议的跑法

1. **先跑 §1 全局项**（跨五关通用），任何一项 FAIL 后面全白跑。
2. **再逐关跑 §2**，每关一次通关从头到尾不中断，边跑边打勾。
3. **§3 独有怪速查**用作现场认人（"这只到底是不是虹吸者"）。
4. **§4 不可回归项**单独复跑一遍，逐项点名确认。
5. 每次跑之前**固定玩家两甲组合**（建议第一遍用 红+蓝，第二遍用 白+黄），因为 S/S' 的划分直接决定你能不能免疫、能不能共振——换一组甲才能验到 §1.2。

### 1.2 配色算法（S / S' 划分）

> 记玩家两甲色集为 `S`（\|S\|=2），补集为 `S'`。

| 观测项 | 期望值 | 判据来源 |
|---|---|---|
| 🔴 目标色 ∈ S | 波次里的"目标色喽啰"**只能是玩家有的两色之一** | 总纲 §E.1-1 |
| 🔴 骚扰色 ∈ S' | "骚扰色喽啰"**只能是玩家没有的两色之一**，且**一律 `hover`**（悬停不逼近） | 总纲 §E.1-2 |
| 🔴 死局检查 | 场上**不存在**任何"必须某色才能破"的护罩/力场/核心，而那色又不在 S 里 | 总纲 可行性铁律 · §H.1 |
| 禁连续 ≥3 同色 | 完整出怪序列里**同色最多连 2 只** | 总纲 §E.1-3（`MAX_RUN=2`） |
| 第 1 波豁免 | **每关第 1 波**不受禁连规则约束（教学波一色到底） | 总纲 §E.1-3 |
| 换甲组合鲁棒性 | 用 **红+蓝** 与 **白+黄** 两组各跑一遍 L1，都能正常配色、无死局 | 实测 |

#### 2.5.1 🔧 L5 四相技能编排建议（工程照此改 `BossCfg`）

> **背景**：engineering-lead 核出「相②不够蓝」—— `_L5_P2 = [ring_white, grid_rain, fan_blue]`，蓝只有 `fan_blue` 一招，整体偏白。这是**编排问题不是数值问题**，所以由设计给池子。

**前提（先对齐，避免改错方向）**

- 红 / 蓝 / 白 / 黄是**四相的主题色**（视觉 + 弹幕主色），**不是护罩色**。
- **护罩色仍从 `S` 内轮转（5.0s）**：\|S\|=2，四相不可能各有固定且 ∈S 的护罩色 —— **可行性铁律优先于主题色**。**不要把相主题色当成护罩色。**

**编排规则（四相通用）**

1. 每相 **3 招**，按序循环。
2. **主色占比 ≥ 2/3**：3 招里至少 2 招是**纯主色**弹幕。
3. 允许 **1 招**是「主色 + 1 个对比色」的双色招（提供视觉层次），但**不得是纯他色**。
4. **唯一例外**：`spiral_4` 是全色旋臂，**只允许相④用它**，作为终相信号。
5. **`ring_white` 是白弹，不得出现在非白相** —— 这就是「相②不够蓝」的根因。

**四相编排表**

| 相 | 主题色 | 循环序 | 招 1 | 招 2 | 招 3 | 备注 |

| **⑦** | 相位者 · 折跃刺客 | 每 **2.6s** 整台化为一层**半透明残影**持续 **1.1s**，期间**完全无敌**（光刃直接穿过 + 弹「相 位」飘字）；**相位结束的瞬间折跃到玩家附近**（距玩家 180~260 随机方位，0.25s 闪白）；相位外每 1.4s 打一发高速瞄准弹（420）。→ **唯一一种会周期无敌 + 瞬移到你脸上的怪** | 相位期打它是纯浪费（尤其引力束甲的过热槽会被白烧） |

## 4. 🔴 不可回归项汇总（单独复跑）

> 判定标准：这一项一旦缺失或走样，**支柱会漂移**，不是数值问题。
> **不允许**为了过门禁、为了省事、为了"先跑通"而临时删掉任何一项。

| # | 不可回归项 | 期望值 | 缺失后果 | 出处 |
|:--:|---|---|---|---|
| **1** | **L1 熔核号全程护罩** | 全程 ∈S 护罩；轮转 **6.5s**；切换前 **1.5s** 预告；狂暴后 **3.5s** | **L1 的换甲教学没有载体**——玩家要到 L4 才第一次被迫为"打 Boss"换甲，支柱漂移 | §D.1 / §5.1 |
| **2** | 同色免疫 + 同源共振 ×1.5 | 穿 A 甲：A 色弹不掉血；A 甲打 A 色敌 ×1.5 | 换甲失去意义，游戏退化为纯走位弹幕 | §1.1 |
| **3** | 涉色机制颜色 ∈ S | 护罩 / 力场 / 核心色**只能**取自玩家两甲 | 出现"必须某色才能破而玩家没有"的死局 | §1.2 |
| **4** | 骚扰色 ∈ S' 且恒 `hover` | 骚扰色只用玩家没有的两色，且**一律悬停** | 骚扰与目标的分工崩塌，S/S' 二分法失效 | §1.2 |
| **5** | `MAX_RUN=2` + 第 1 波豁免 | 同色最多连 2；每关 W1 豁免 | 配色节奏塌成随机 | §1.2 |

| **7** | 列阵组 3 艘**不是** `no_block_clear` | 3 艘必须打掉才清场 | 变成"可以无视的墙"，L3 的空间切割压力消失 | §1.3 |
| **8** | L4 双战将**强制异色** | W4/W5 两只战将力场色不同 | 一甲打穿两场，L4 换甲教学被稀释 | §2.4 |
| **9** | L5 **4 阶段** + 3 个刻度 | `_BOSS_PHASES[4]=4`，`phase_marks()==[0.75,0.50,0.25]` | L5 退化为"L4 更快版"，四相辨识度消失 | §2.5 |
| **10** | 品阶**按关独立** | 每关自己的完成度阈值，非全局 | 前 4 关永远拿不到金勋 / 第 5 关白送金勋 | §1.4 / §J.1 |
| **11** | 通关 N 解锁 N+1 · 已通关可重玩 | 二者都要成立 | 进度系统不成立 | §1.5 |
| **12** | 无第五属性色 | 灰/紫只能是材质，不带免疫与共振语义 | 四色系统被污染 | §1.1 / §J.8-2 |
| **13** | L5 掉落 **0.14** | 不是 0.18 | 续航考验消失，L5 只是"更长"而非"更缺" | §2.5 / §J.4 |

## 5. 三条高风险项专章（team-lead 点名）

### 5.1 🔴 L1「熔核号」全程护罩 —— 教学载体

**为什么是不可回归项**：L1 的换甲教学 **100% 建立在**这层全程护罩上。它是全游戏最干净的换甲教科书 ——「看下一色预告 → 提前换好 → 罩一落就打满」。如果 L1 不展护罩，这条教学就**没有载体**，玩家要到 L4 才第一次被迫为"打 Boss"而换甲。

| 子项 | 期望值 | 怎么测 |
|---|---|---|
| 全程性 | 进场 3s 内就有护罩；**中途任何时刻**（含阶段切换、狂暴、濒死）护罩都在 | 全程盯着护罩环，看它有没有消失过 |
| 轮转 CD | 常态 **6.5s** | 掐表两次换色的间隔 |
| 预告 | 换色前 **1.5s** 护罩边缘闪下一色 | 看能不能**提前读出**下一个颜色（读不出来即 FAIL） |
| 预告在狂暴后仍可读 | 狂暴后预告缩到 **1.0s**，但**必须仍然看得见** | 狂暴后掐 1.0s，确认仍可预判 |
| 狂暴 CD | 跌破 30% 后 **6.5s → 3.5s** | 掐表 |
| 色 ∈ S | 护罩色**永远**是玩家两甲之一 | 换一组甲再跑一次验证 |
| 本体不抢注意力 | 本体恒为光子白，**不随护罩变色**；只有护罩环在变 | 看视觉焦点是不是落在护罩环上 |
| 异色惩罚 | 异色 **×0.60** —— 硬打能过但**明显变慢** | 故意全程不换甲打一次，记录耗时差 |

### 5.2 🟠 L4「深渊之喉」`EXPOSED` 模式 —— 全项目唯一未被自测覆盖的护罩模式

**为什么单列**：L1/L5 是 `ALWAYS`、L2/L3 是 `NONE`，只有 L4 是 `EXPOSED`（**仅在暴露期展罩**）。这是三种模式里唯一有**状态迁移**的，也是自测覆盖的空白。

**完整状态机（照此逐迁移验证）**：

| 状态 | 进入条件 | 期间表现 | 退出条件 |
|---|---|---|---|
| **护罩期**（相位壁） | 子核心**存活**（任意 ≥1 只） | 主核心免伤 **80%**；**不展属性护罩**；子核心每 4.0s 召 2 只增援（∈S'，场上 ≤6） | 子核心**全部**被击杀 |
| **暴露期** | 子核心全灭 | ① 相位壁消失 ② 本体**全额**受伤 ③ **展开属性护罩**（∈S，异色 ×0.60） | 持续 **6.0s** 到时 |
| **重新分裂** | 暴露期结束 | 重新分裂出 N 只子核心（P1=1 / P2=2 / P3=2），回到护罩期 | — |

| 子项 | 期望值 | 怎么测 |
|---|---|---|
| 触发条件 | **必须是"子核心全灭"**，不是计时、不是血量 | 故意只杀 1 只（P2/P3 有 2 只），确认**不**进暴露期 |
| 时长 | 常态 **6.0s**；狂暴后 **4.5s** | 掐表 |
| 暴露期三件事齐 | 相位壁消失 **且** 全额受伤 **且** 展护罩 | 三件逐个确认，**缺一件即 FAIL** |
| 护罩色 ∈ S | 暴露期护罩色是玩家两甲之一 | 换甲组再跑一次 |
| 伤害共享 | 打子核心，本体血**同步掉 40%** | 看 Boss 血条在只打子核心时是否下降 |
| 免费暴露期 | 每次阶段切换（67% / 34%）时**全部子核心自爆** → 白送一次暴露期 | 阶段切换瞬间确认进入暴露期 |
| 狂暴变化 | 跌破 30%：子核心**常驻 2 只不再消失**、召唤 4.0s→2.0s、暴露期 6.0s→4.5s | 逐项掐表/计数 |
| 🟠 狂暴后仍可通关 | 子核心常驻 ≠ 无敌；仍要能杀光 → 仍能进暴露期 → 仍能击杀 Boss | **必须实际打死一次**，否则会出现不可通关的死锁 |
| 增援上限 | 场上增援**不超过 6 只** | 数场上的增援数 |

### 5.3 🟠 L3「耀斑号」散热期 —— 输出窗口制

**为什么单列**：这是全游戏**唯一**一个"输出窗口制"Boss。窗口的三件事必须**同时成立、同时复位**，任何一件漏掉，窗口就从"奖励"变成"惩罚"。

| 子项 | 期望值 | 怎么测 |
|---|---|---|
| 常态减伤 | **70%**，**与颜色无关**（穿什么甲都一样） | 换甲打，确认倍率不变；再用异色打，确认也不变 |
| 常态不为零 | 常态**仍能**造成伤害（30%），不是完全免疫 | 打一下看掉不掉血 |
| 🔴 窗口三件事 | ① 舱盖打开露出内核（**读得出来**）② **停止射击** ③ 伤害 **×3.0** | 三件逐个确认，**缺一件即 FAIL** |
| 🔴 三者同时复位 | 窗口结束：舱盖合上、**恢复开火**、倍率回 ×0.3 | 窗口结束瞬间确认**重新开始挨打**（若窗口结束后仍停火，说明漏复位了一件） |
| 🔴 窗口内**不叠共振** | 窗口内**任意颜色**都只有 ×3.0；穿甲不带来任何额外倍率 | 窗口内用同色甲打，再用异色甲打，**两次伤害必须一样**（不一样即 FAIL）。<br>判据：L3 `_WARD_MODE=NONE` → `ward=-1`、`body_color=-1`，**没有"同色"可定义**；本关答案是**打满命中率，不是换对颜色** |
| 时长递减 | P1 **3.0s** → P2 **2.2s** → P3 **1.6s** | 每阶段各掐一次 |
| 阶段切换奖励 | 每次切换立刻进一次 **3.0s** 窗口 | 67% / 34% 切换瞬间确认 |
| 狂暴 | 跌破 30%：窗口 **→1.2s**、倍率 **×3.0 → ×4.0**、**窗口结束喷冲击环（半径 180）** | 三项逐个确认 |
| 打完就撤 | 冲击环的存在**确实**逼你撤离（不是装饰） | 站在原地吃一次，确认会掉血 |

## 7. 实测矩阵建议（给 engineering-lead 排期）

| 轮次 | 战甲组合 | 覆盖范围 | 目的 |
|:--:|---|---|---|
| **R1** | 红 + 蓝 | L1 → L5 全通 | 主路径；S={红,蓝}、S'={白,黄} |
