## 1 · 一句话总纲

> **「属性 = 剪影本体，关卡 = 挂载器官，难度 = 色调与密度。」**

把一个已存在的事实摊开讲：`PirateArt` 现在的**主体多边形是绑在颜色上的**——
红=六边兽首、蓝=六边菱壳、黄=八边符牌、白=圆壳。
这条绑定**不是历史包袱，是玩法资产**：玩家靠「哪块高饱和 MAIN 实心块最大」判断该换哪件甲
（文件头「硬底线」已明载）。

所以五关差异化**绝不能动主体剪影**，只能动主体之外的东西。
下面 A 节的五条维度就是在这个前提下挑出来的。

**D1 为什么排第一**：器官是唯一能**改变外轮廓**的维度——而外轮廓是余光读取的唯一通道。
弹幕射击里玩家 90% 的时间不看敌人、只看弹，识别必须发生在余光里，**只有轮廓能做到**。

### A.2 器官的两个安全插入位（**本文档最重要的一条工程约定**）

现有层序是铁律：

```
① 气息光晕 → ② +X 尾 → ③ DARK 外壳 → ④ MAIN 主体 → ⑤ DARK 结构线
  → ⑥ GLOW 尖刺/顶冠 → ⑦ 装饰 → ⑧ CORE 主核
```

在此基础上**只开两个插入位**，其余一律不动：

| 插入位 | 时机 | 用于 | 理由 |
| --- | --- | --- | --- |
| **②b** | ② 尾之后、③ 外壳之前 | **背负型器官**：环、翼、触须、分身/残影 | 必须压在主体**之下**，才像「背在身上的东西」；若画在主体之上会糊住 MAIN 实心块，破坏换甲判据 |
| **⑦b** | ⑦ 装饰之后、⑧ CORE 之前 | **外突型器官**：炮列、甲片、外置炮口、刃 | 必须压在主体**之上**才能成为轮廓的一部分；但**必须在 CORE 之前** |

> ⚠️ **器官绝对禁止画在 ⑧ 之后。** CORE 主核是「−X 方向、贴近原点」的**唯一要害指针**
> （「瞄圆心即命中」）。任何关卡内容盖住它 = 玩家瞄准判据失效。

## B · 通用怪 vs 独有怪的视觉层级规则

### B.1 三层强度模型（同母题，三档强度）

**每关只有一套器官母题**，三种单位按强度复用它 —— 这是「一眼认出这是第几关」的机制保证：

| 强度档 | 谁在用 | 器官画法 | GLOW α | 尺寸 | 是否带 CORE 描边 | 增量 draw |
| --- | --- | --- | --- | --- | --- | --- |
| **W（弱化）** | 通用四色喽啰（星盗机兵） | **1 件**，②b 或 ⑦b（按母题定） | **0.45** | 母题 ×**0.60** | ❌ 无 | **≤2** |
| **M（中）** | 通用精英（星盗战将） | **1 件 + 镜像件**，②b | **0.70** | 母题 ×**1.00** | ❌ 无 | **≤4** |
| **S（强化）** | **本关独有怪（7 种）** | **2~3 件**，②b 与 ⑦b 各占一部分 | **0.85** | 母题 ×**1.25** | ✅ 有（1px `COLOR_CORE[c]`，仅描器官外缘） | **2~5** |
| **B（标志）** | **本关 Boss** | 器官即本体的一部分 | 0.85~1.0 | 见 C.1 | ✅ 有 | **≤24** |

> **为什么独有怪必须带 CORE 描边而喽啰不带**：CORE 是「要害/重要」的视觉语法。
> 喽啰满屏都是 CORE 描边 = 语法通货膨胀，独有怪就再也「独」不起来了。

### B.2 独有怪的定位：填尺寸空档，不抢战将的压迫感

| 单位 | 碰撞半径 | 主体顶点倍率 | 视觉上限（含器官） |
| --- | --- | --- | --- |
| 通用喽啰（小妖） | **19** | ×1.00 | r26 |
| **本关独有怪** | **20~26**（逐 kind 定） | ×**1.25** | **r36** |
| 通用精英（战将） | **34** | ×1.70 | r40 |

**独有怪的识别度来自「器官最张扬」而不是「体型最大」** ——
主体比战将小一圈，但器官探到 r36 且带 CORE 描边，读起来是「小身板挂满外挂的特种机」，
与战将的「大体型重甲」形成**体型/张扬度的反向对比**。

### B.3 独有怪的颜色：**必须落在四色内**（硬结论，不是建议）

**结论：独有怪的颜色必须 ∈ {电浆红, 寒霜蓝, 光子白, 引力黄}，不得引入第五套属性色。**

1. **玩法绑定（致命）** —— 颜色不是装饰，是三套机制的输入：
   - `Enemy.hit()` / `Elite.hit()`：**同色共振 +50%**；
   - `Player.take_hit()`：战将**免疫同色弹**；
   - `Boss._ward()` / `Elite.setup()`：**护罩色与力场色「只从玩家已选的两件战甲中抽取」**
     （`Elite.gd` 文件头：「凭空给个玩家没带的颜色，破力场就成了死局 —— 那不是难度，是设计事故」）。
   引入第五色 → 玩家永远打不出 +50%、永远免疫不了、力场色池对不上 → **直接产生死局**。
2. **可读性** —— 四色是「该换哪件甲」的唯一编码，第五色会污染这条通道。
3. **成本** —— 第五色要新增 MAIN/GLOW/DARK/CORE 四档 + 重调所有占比断言。

> **L3 列阵者 ∈ S'**：它吃的是**骚扰色**（玩家没选的两色之一），所以玩家**永远免疫不了它、也拿不到 +50%**。
> 这是设计意图（它就是一堵「硬墙」，逼走位而不是逼换甲）。
> 视觉上**必须让人一眼看出"这堵墙打不动"**：列阵者用**最高比例的中性装甲色（35%）+ 连续的炮列线条**，
> 让它的剪影读起来像「一整片装甲壁垒」而不是「三只怪」。

#### 但**允许**引入中性色作为「材质色」

沿用 `build_robes.py` 已有的 `NEUTRAL (0.74, 0.78, 0.86)`（装甲金属灰）—— **零新增语义**。

| 规则 | 值 |
| --- | --- |
| 中性色只用在 **器官与结构件** | ✅ |
| 中性色**绝不用**于 ④ 主体实心块 | ❌ 否则换甲判据失效 |
| 中性色**绝不出现**在 CORE 附近 20px 内 | ❌ CORE 只能用 `COLOR_CORE[c]` |
| 中性色面积 ≤ **主体 MAIN 面积的 25%**（列阵者例外放宽到 35%，见上） | 保证扫一眼仍是 MAIN 高饱和占主导 |
| 中性色**不得形成闭合大色块**（单块 ≤ 主体 8%） | 防止它抢轮廓 |

> **一句话判据**：中性色是**材质**，不是**属性**。玩家看到的「大块颜色」必须永远是四色之一。

`sh.radius = EnemyKind.radius_of(kind)`（GRUNT 19 / 拆解者 23 / 变节者 22 / 列阵者 24 / 敷设者 26 / 虹吸者 22 / 殉爆者 26 / 相位者 20）。
**若工程选择零改动，全部维持 r19 也可** —— 识别度主要来自器官（B.2）。

1. **`boss.png` 退役，5 个 Boss 全部矢量（含 L1）。**

红是电浆弹的色相带，`06` §1.2 明令 L0 禁止使用四档属性色色相带。
压迫感来自**明度 + 彩度衰减 + 速度感 + 层次密度**，不来自色相。

> **为什么避开 `COLOR_MAIN` 的精确值**：四色是**玩法判据**（"这是电浆弹"），UI 强调色若用同一组值，

### I.3 未解锁态：**弃用「整卡 alpha 0.35」**

**改用「去色 + 斜封条 + 锁形 + 占位行」四件套**（卡底与卡框保持 α1.0）：

| 手段 | 做法 | 通道 |
| --- | --- | --- |
| **去色（主）** | 强调色 → **中性灰** `Color(0.52, 0.55, 0.66)`；卡名 `Color(0.62,0.66,0.78)`；参数数值 `Color(0.60,0.64,0.76)` | 明度 + 彩度 |
| **斜封条（主视觉）** | 卡面对角 **16px 宽斜带**（`draw_colored_polygon` 四点，从左下 `(x0+8, 564)` 到右上 `(x0+208, 184)`），色 `Color(0.10,0.10,0.14,0.55)`；带上居中写「未 解 锁」11 号字 `Color(0.78,0.82,0.95)`（**必须走 `DrawUtil.txt()`**） | **形状 + 文字** |
| **锁形标识** | 关号徽章位改画锁：`draw_rect` 锁体 14×11 + `draw_arc` 锁梁（半圆 r5），色 `Color(0.72,0.76,0.88)`。**纯几何、零素材** | **形状** |
| **占位行** | 5 行参数**不隐藏**，改显示标签 + `— — —`，色 `Color(0.45,0.48,0.60)`。保证 5 张卡等高、版式一致 | 排版一致 |
| **副标题** | 副标题位改显示 **「通关第 N-1 关开启」**（N = 本关号），12 号 `Color(0.62,0.66,0.78)` | **文字** |

**选中态**：锁卡可被 ← → 停住并聚焦，但：
- 选中框**也走中性灰**（不能是彩色）—— 否则"去色表达锁定"被选中框推翻；
- `_confirm()` 拒绝并 `Fx.pop`「未 解 锁」。

**可访问性自检**：锁态有 **形状（锁形 + 斜封条）+ 文字（未解锁 + 通关第 N-1 关开启）** 两条冗余通道，
**不依赖颜色** ✅。对角斜线在 5 张卡并排时比 alpha 更能远距离识别。

> **扫描线（可选，不推荐）**：若想要"数据未解码"质感，卡面每 **≥12px** 画一条 1px 横线
> `Color(0.06,0.06,0.10,0.18)`，且**只画在未解锁卡上**。6px 间距 = 264 次 `draw_line`（超标），
> 12px = 33 条/卡（可接受）。我倾向**不做** —— 斜封条已把"锁定"说清楚了。
