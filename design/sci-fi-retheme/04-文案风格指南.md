# 04 · 文案风格指南（太空歌剧 · 星舰战争）

> 供 engineering-lead 落文案、quality-lead 做扫描、art-director 对齐视觉基调。

## 1. 题材定位

- **题材**：太空歌剧 · 星舰战争（Space Opera）。硬派军事底色 + 史诗浪漫高光。
- **战场**：星际边境。玩家是星舰战士（装甲单兵），敌为星盗（星际盗匪武装），大反派为星盗旗舰（五关 Boss 统称；各有代号：熔核号/霜噬号/耀斑号/深渊之喉/终焉号）。
- **品类词保留**：「弹幕」「弹」「伤害」「护盾」「无敌」等射击游戏通用词不动。

## 2. 语气基调（硬派军事 : 史诗浪漫 = 6 : 4）

- **硬派军事（主）**：术语精确、短促、有金属感。用「出刃 / 破罩 / 力场 / 护罩 / 星袭 / 出征 / 阵亡」这类干脆动词。
- **史诗浪漫（辅）**：Boss 登场、狂暴、结算凯旋等情绪节点允许稍长的史诗措辞（「星盗旗舰 · 现身」「旗舰周身泛起血光」）。
- 避免网络梗、卖萌、现代口语。

## 3. 人称与单位规范（全篇统一）

| 项 | 统一用法 | 禁用 |
|---|---|---|
| 玩家身份 | 星舰战士 / 驾驶员（正文用「战士」，HUD 省略主语） | 修士 / 道人 / 真人 |
| 玩家生命 | 生命（HP） | 元神 / 气血 / 真元 |
| 玩家护盾 | 护盾（光子盾甲的盾） | 罡气 / 法罡 / 罡 |
| 玩家外观 | 战甲 | 道袍 / 皮肤 / 法衣 |
| 玩家武器 | 光刃（双排/单排） | 飞剑 / 剑 / 御剑 |
| 引力束甲武器 | 引力束 | 符光 / 符箓 |
| **敌方势力** | **星盗**（太空海盗武装，势力层） | — |
| 敌方杂兵 | **星盗喽啰**（玩家可见串；四色：电浆/寒霜/光子/引力星盗喽啰）。三层：势力=星盗、单位=喽啰、形态描述=无人兵器（仅文档/注释，见 §2 注） | 小妖 / 妖 / 魔修 |
| 敌方精英 | 星盗战将（星盗阵营的精英机） | 护法妖将 / 妖将 |
| 敌方 Boss | **星盗旗舰**（统称；紧凑「旗舰」；五关代号 熔核号/霜噬号/耀斑号/深渊之喉/终焉号；称号 星盗先驱/星盗霜舰/星盗炮垒/星盗母舰/星盗王） | 血魔老祖 / 老祖 / 始祖 / 母舰核心 / 巢舰核心 |
| 波次 | 波（第 N 波 · 星袭） | 重（妖潮） |
| Boss 阶段 | 阶段（第 N 阶段） | 法相 / 重法相 |
| Boss 护罩 | 护罩（旗舰能量护罩） | 法罩 |
| Boss 狂暴 | 核心过载（沿用「狂暴」亦可） | — |
| 精英护盾 | 力场 | 法罡 |
| 货币/分数 | 星币 | 灵石 |
| 道具 | 修复包 / 刃影模块 / 增幅核心 / 力场罩 | 回春丹 / 剑影符 / 增攻符 / 无量罩 |

> **舰 vs 机**：本作玩家是**装甲单兵**（非驾驶整艘舰），故玩家侧统一用「战甲 / 战士」，不用「舰 / 机」作**玩家**称谓。**例外**：Boss 统称「星盗旗舰」、L4「星盗母舰」是敌方 Boss 称号，允许用「舰」。

> **杂兵三层命名（team-lead RT-07 终裁，免后人再纠结）**：
> - **势力层** = 「星盗」（太空海盗武装，谁）；
> - **单位称呼层** = 「喽啰」（杂兵个体；**玩家可见字符串一律用「星盗喽啰」**）；
> - **形态描述层** = 「无人兵器」（仅用于设计文档与 `.gd` 注释，描述其机械无人形态，**不进玩家可见字符串**）。
> 「无人兵器」是合法形态描述词，**已移出硬黑名单**；但玩家可见层不出现它。

## 4. 四色属性命名规范（全篇统一，禁止混用）

| 色 | 统一名 | 形容词 | 组合示例 |
|---|---|---|---|
| 红 | 电浆 | 电浆弹 / 电浆星盗 | 「免疫电浆弹」 |
| 蓝 | 寒霜 | 寒霜弹 / 寒霜星盗 | 「寒霜疾甲」 |
| 白 | 光子 | 光子弹 / 光子星盗 | 「光子护盾」 |
| 黄 | 引力 | 引力弹 / 引力星盗 | 「引力束」 |

> 四色总称「四色能量弹 / 四色能量」。禁止再出现「赤炎/玄冰/太清/戊土」及「五行（火/水/土/金行）」表述。
> 战甲职能标签用「电浆·攻 / 寒霜·速 / 光子·守 / 引力·术」，不再用「火行/水行/无行/土行」。

## 5. 修仙词汇黑名单（quality-lead 全项目扫描用）

以下词**禁止**出现在任何 `.gd` 字符串、注释、`.tscn`、`project.godot`、资产命名中（资产文件名如 `robe_*.png` 属技术键，见 03 协同点）：

```
修仙 修真 修士 道人 真人 元神 气血 真元 灵气 灵力
道袍 法衣 皮肤(指外观时) 飞剑 御剑 剑诀 本命飞剑
符光 符箓 符牌 符袍 剑影符 增攻符 回春丹 无量罩
赤炎 玄冰 太清 戊土 火行 水行 土行 金行 五行
小妖 妖物 妖将 护法妖将 妖潮 妖王 血魔老祖 老祖
法罡 法罩 法相 法珠 法眼 魔道法相 罡气 罡
灵石 问道 道成 道消 此劫 渡劫 入劫 入定
回春 剑影 增攻 无量(指道具时)
始祖 母舰核心 巢舰核心(「始祖」源自血魔老祖遗留，「母舰核心」为 08 作废词)
```

> **势力名例外**：「星盗」是敌方**势力**层称谓，**允许保留**；指**单位**时落到「星盗喽啰」（杂兵，玩家可见）/「星盗战将」（精英）。
> Boss 统称一律「星盗旗舰 / 旗舰」，禁用「始祖」「母舰核心」「巢舰核心」「老祖」等含血统/生物联想的名。

> **Boss 名白名单（五关代号 + 称号，允许保留，勿被扫描器误抓）**：
> 星盗旗舰 / 旗舰 / 熔核号 / 霜噬号 / 耀斑号 / 深渊之喉 / 终焉号 / 星盗先驱 / 星盗霜舰 / 星盗炮垒 / 星盗母舰 / 星盗王 / 星盗喽啰。
> （「无人兵器」为合法形态描述词，仅文档/注释层，见 §2 三层注。）

> 例外白名单（这些词允许保留，非题材词）：
> - 「弹幕」「弹」「护罩」（新词，非「法罩」）、「力场」（新词，非「法罡」）
> - 「狂暴」（通用）、「阶段」（通用）、「抗性」「击穿」
> - 「壹/贰」（择袍序号，纯数字大写，无题材含义，保留）
> - 代码标识符 `ward/phase/armors/armor_idx` 等英文，不在中文黑名单内

## 6. 排版约束（务必遵守，UI 是纯 `_draw()` 手绘）

- HelpScreen 两列：行距 21、字号 15、列宽 528，末行不得压到底部提示（H-30）。改写条目长度 ≤ 原条目 ±20%。
- 所有 `_draw()` 文字无自动布局，改词后须复核该处是否有固定宽度/居中对齐，避免溢出或错位。
- 标题类大字（如「星 际 弹 幕」）保留字间空格风格，字数与原一致。
- 详见 02 每条的字数标注与 05 的成组核对清单。
