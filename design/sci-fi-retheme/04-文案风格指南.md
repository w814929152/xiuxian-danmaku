# 04 · 文案风格指南（太空歌剧 · 星舰战争）

> 供 engineering-lead 落文案、quality-lead 做扫描、art-director 对齐视觉基调。

## 1. 题材定位

- **题材**：太空歌剧 · 星舰战争（Space Opera）。硬派军事底色 + 史诗浪漫高光。
- **战场**：星际边境。玩家是星舰战士（装甲单兵），敌为星盗（星际盗匪武装），大反派为星盗始祖（盗匪统帅 / 旗舰）。
- **品类词保留**：「弹幕」「弹」「伤害」「护盾」「无敌」等射击游戏通用词不动。

## 2. 语气基调（硬派军事 : 史诗浪漫 = 6 : 4）

- **硬派军事（主）**：术语精确、短促、有金属感。用「出刃 / 破罩 / 力场 / 护罩 / 星袭 / 出征 / 阵亡」这类干脆动词。
- **史诗浪漫（辅）**：Boss 登场、狂暴、结算凯旋等情绪节点允许稍长的史诗措辞（「星盗始祖 · 现身」「始祖周身泛起血光」）。
- 避免网络梗、卖萌、现代口语。

## 3. 人称与单位规范（全篇统一）

| 项 | 统一用法 | 禁用 |
|---|---|---|
| 玩家身份 | 星舰战士 / 驾驶员（正文用「战士」，HUD 省略主语） | 修士 / 道人 / 真人 |
| 玩家生命 | 生命（HP） | 元神 / 气血 / 真元 |
| 玩家护盾 | 护盾（光子盾甲的盾） | 罡气 / 法罡 / 罡 |
| 玩家外观 | 战甲 | 道袍 / 皮肤 / 法衣 |
| 玩家武器 | 光刃（双排/单排） | 飞剑 / 剑 / 御剑 |
| 引力束甲武器 | 引力束 | 符光 / 符箓 |
| **敌方势力** | **星盗**（太空海盗武装，势力层） | — |
| 敌方杂兵 | **星盗无人兵器**（紧凑句「星盗机兵」；四色无人兵器） | 小妖 / 妖 / 魔修 / 星盗（指单位时须落到「无人兵器」） |
| 敌方精英 | 星盗战将（星盗阵营的精英机） | 护法妖将 / 妖将 |
| 敌方 Boss | **母舰核心**（全名 星盗母舰核心；紧凑「核心」） | 血魔老祖 / 老祖 / 始祖 / 巢舰核心 |
| 波次 | 波（第 N 波 · 星袭） | 重（妖潮） |
| Boss 阶段 | 阶段（第 N 阶段） | 法相 / 重法相 |
| Boss 护罩 | 护罩（母舰核心能量护罩） | 法罩 |
| Boss 狂暴 | 核心过载（沿用「狂暴」亦可） | — |
| 精英护盾 | 力场 | 法罡 |
| 货币/分数 | 星币 | 灵石 |
| 道具 | 修复包 / 刃影模块 / 增幅核心 / 力场罩 | 回春丹 / 剑影符 / 增攻符 / 无量罩 |

> **舰 vs 机**：本作玩家是**装甲单兵**（非驾驶整艘舰），故统一用「战甲 / 战士」，不用「舰 / 机」。星舰作为背景载具出现在美术与世界观里，UI 文案不出现「舰」作玩家称谓。

## 4. 四色属性命名规范（全篇统一，禁止混用）

| 色 | 统一名 | 形容词 | 组合示例 |
|---|---|---|---|
| 红 | 电浆 | 电浆弹 / 电浆星盗 | 「免疫电浆弹」 |
| 蓝 | 寒霜 | 寒霜弹 / 寒霜星盗 | 「寒霜疾甲」 |
| 白 | 光子 | 光子弹 / 光子星盗 | 「光子护盾」 |
| 黄 | 引力 | 引力弹 / 引力星盗 | 「引力束」 |

> 四色总称「四色能量弹 / 四色能量」。禁止再出现「赤炎/玄冰/太清/戊土」及「五行（火/水/土/金行）」表述。
> 战甲职能标签用「电浆·攻 / 寒霜·速 / 光子·守 / 引力·术」，不再用「火行/水行/无行/土行」。

## 5. 修仙词汇黑名单（quality-lead 全项目扫描用）

以下词**禁止**出现在任何 `.gd` 字符串、注释、`.tscn`、`project.godot`、资产命名中（资产文件名如 `robe_*.png` 属技术键，见 03 协同点）：

```
修仙 修真 修士 道人 真人 元神 气血 真元 灵气 灵力
道袍 法衣 皮肤(指外观时) 飞剑 御剑 剑诀 本命飞剑
符光 符箓 符牌 符袍 剑影符 增攻符 回春丹 无量罩
赤炎 玄冰 太清 戊土 火行 水行 土行 金行 五行
小妖 妖物 妖将 护法妖将 妖潮 妖王 血魔老祖 老祖
法罡 法罩 法相 法珠 法眼 魔道法相 罡气 罡
灵石 问道 道成 道消 此劫 渡劫 入劫 入定
回春 剑影 增攻 无量(指道具时)
始祖 巢舰核心(生物化「巢」联想，Boss 统一用「母舰核心」)
```

> **势力名例外**：「星盗」是敌方**势力**层称谓，**允许保留**；但指**单位**时必须落到「星盗无人兵器」（杂兵）/「星盗战将」（精英），不得单独用「星盗」泛指杂兵。
> Boss 一律「母舰核心 / 核心」，禁用「始祖」「巢舰核心」「老祖」等含血统/生物联想的名。

> 例外白名单（这些词允许保留，非题材词）：
> - 「弹幕」「弹」「护罩」（新词，非「法罩」）、「力场」（新词，非「法罡」）
> - 「狂暴」（通用）、「阶段」（通用）、「抗性」「击穿」
> - 「壹/贰」（择袍序号，纯数字大写，无题材含义，保留）
> - 代码标识符 `ward/phase/robes(待改armors)/robe_idx(待改armor_idx)` 等英文，不在中文黑名单内

## 6. 排版约束（务必遵守，UI 是纯 `_draw()` 手绘）

- HelpScreen 两列：行距 21、字号 15、列宽 528，末行不得压到底部提示（H-30）。改写条目长度 ≤ 原条目 ±20%。
- 所有 `_draw()` 文字无自动布局，改词后须复核该处是否有固定宽度/居中对齐，避免溢出或错位。
- 标题类大字（如「星 际 弹 幕」）保留字间空格风格，字数与原一致。
- 详见 02 每条的字数标注与 05 的成组核对清单。
