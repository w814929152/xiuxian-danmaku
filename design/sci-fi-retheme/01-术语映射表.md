# 01 · 术语映射表（修仙 → 太空歌剧·星舰）

> 核心交付。本表覆盖玩法概念、实体、界面、计分、难度、波次、Boss 形态、精英法罡、四色属性。
> 「建议新标识符」一列只给**结论**；完整逐文件改动与「不动清单」见 `03-标识符重命名清单.md`。
> 所有可直接粘贴进代码的成品中文，见 `02-替换文案清单.md`。

## 0. 命名总原则

1. **题材外壳全换，玩法数值不动。** 枚举值、伤害、血量、阈值、碰撞半径等一律保留。
2. **中文术语统一 2 字优先**（四色属性、HP/护盾、货币、波次单位），避免压坏 `_draw()` 手绘排版。
3. **英文标识符能不改就不改**：颜色枚举、存档 JSON 键、对象池 key、类名（除 Robe 族外）全部保留，理由见 03。
4. **人称/单位统一**：全篇称「舰」（星舰战士 / 舰体 / 旗舰），不再用「修士 / 元神 / 老祖」。

## 8. 关键「不动清单」摘要（详见 03）

- 颜色枚举 `C { RED=0, BLUE=1, WHITE=2, YELLOW=3 }` 与 `Game.RED/BLUE/WHITE/YELLOW` 及数值——**数据轴 + 存档键**，不动。
- `COLOR_MAIN/GLOW/DARK/CORE` 四组 Color 数组——不动（只改 `COLOR_CN` 内容）。
- `Sword` 类名、`POOL_KEY="sword"`、`sword_player` 纹理键——技术标识符，不动。
- `Beam/Danmaku/Enemy/Elite/Boss/Pickup` 等英文类名——不动（中文注释改）。
- `ward/phase/enraged/RAGE_*/WARD_*` 等英文标识符——语义通用，不动（中文改）。
- 存档路径 `user://highscores.json` 与 JSON 键 `"robes"/"rank"/"score"/"win"`——**为旧存档兼容，键名保留**（见 03 迁移方案）。
- 项目目录名 `xiuxian-danmaku`、`export_presets.cfg`、两个 `.bat` 内路径——**一律不动**。
